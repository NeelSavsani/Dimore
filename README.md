# Dimore Architectural Systems

A modern, responsive, high-performance web application rebuild for [Dimore Architectural Systems](https://dimore.co.in).

## Features
- **Semantic HTML5 & Vanilla CSS**: Engineered with high aesthetic fidelity, fluid responsiveness, and zero bloated frameworks.
- **Modern Typography & Design System**: Google Fonts `Outfit` and `Plus Jakarta Sans`, rich dark slate palette with luxury gold/bronze accents.
- **Complete Rebuilt Pages**:
  - `index.html` - Home page featuring sticky navigation, hero showcase, 6-step architectural solution, masonry gallery with fullscreen lightbox, products showcase, filterable project portfolio, testimonials carousel, and consultation enquiry form.
  - `about-us.html` - Company story with Qutone Ceramic partnership, architectural philosophy, and 6 core performance engineering pillars.
  - `career.html` - Life at Dimore culture showcase, active job openings, and interactive job modal with fast application form.
  - `contact-us.html` - Interactive Google Maps embed for the Qutone Experience Centre (Sindhu Bhavan Marg, Ahmedabad), direct messaging form with validation, and direct contact details.
- **Client-Side Interactivity**: Lightbox modal, mobile drawer menu, portfolio filtering, read-more collapsible toggles, testimonial carousel, and form validations in `js/main.js`.
- **Verified Assets**: All authentic brand graphics and imagery verified locally.

## Getting Started
Open `index.html` in any modern web browser or serve locally:
```bash
python -m http.server 8088
```
Visit `http://localhost:8088`.
